# Delivery Operations & Profitability Analytics

A synthetic end-to-end BI portfolio project for analyzing delivery operations, warehouse performance, customer segments, and profitability.

## Architecture
Synthetic Raw Data → Snowflake → SQL cleaning/transformation → Star Schema → Power BI → DAX → Dashboard

## Deliverables
- Power BI dashboard (`.pbix`) — add locally because Power BI files are not generated by this workspace.
- Project report (PDF)
- Power BI user guide (PPTX)
- Data Architect document (DOCX)
- Synthetic dataset package (ZIP)

## Report pages
1. Executive Overview
2. Delivery Performance — Operational Analysis / Profitability Analysis
3. Warehouse Details — drill-through page

## Power BI features
- Slicers
- Page navigation
- Bookmark-based view switching
- Field parameter metric switch
- Custom report-page tooltip
- Warehouse drill-through
- Row-Level Security by region

## Data disclaimer
All data in this project is synthetic/simulated and is intended for portfolio and demonstration purposes only.
